# Tourism Management System
Data Structures labs 02-07 (individual project).

| Lab | Data structure | Tourism use case |
|-----|----------------|------------------|
| Lab02_Stack | Stack | Tourist return journey |
| Lab03_Queue | Queue | Tour booking requests |
| Lab04_PriorityQueue | Priority Queue | Tourist support desk |
| Lab05_SinglyLinkedList | Singly Linked List | Tour destination list |
| Lab06_CircularLinkedList | Circular Linked List | Sightseeing bus route |
| Lab07_DoublyLinkedList | Doubly Linked List | Travel itinerary navigator |

Each lab folder has main.cpp, a structure file, a class header, a class member-function file and its own README with compile instructions.
